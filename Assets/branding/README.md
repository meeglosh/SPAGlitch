# SPAGlitch app icon

Original vector artwork: evergreen rounded tile, split circular halo, and a
mint/cyan electrical strike. Matches the rounded tile and circular visual
language of SPASynth's app_icon.svg and the supplied SPAStation Dock reference.

app-icon.svg is the editable source. app-icon.png is a transparent 1024px render
using CairoSVG. JUCE ICON_BIG/ICON_SMALL generate macOS ICNS and Windows ICO.
Quick Look renders opaque white margins; use CairoSVG to retain transparency.
